## Gender judgements to check
- s2 line 3 "इसे कहाँ से खरीद सकते हैं?" and line 5 "…जमा कराए जा सकते हैं?" read as impersonal/plural ("can one…"), so no `f`, though the English says "I". If the teacher reads them as the learner speaking of herself, line 3 needs an `f` (सकती हैं is not natural; a rewording would be needed).
- s8 line 1: the senior citizen calls the learner बेटा. Only सकते → सकती was changed in the `f`; बेटा kept (commonly used for girls too). Teacher may prefer बेटी.
- s9 line 1, s10 line 1, s11 line 1, s15 line 1: गया/रहा agree with the object (स्टेशन, टोकन, बैग, द्वार), not the speaker; no `f`.
- All non-learner roles (staff, security officer, co-passenger, senior citizen) are "neutral": none uses a gendered form about itself. Staff only uses plural हम.
