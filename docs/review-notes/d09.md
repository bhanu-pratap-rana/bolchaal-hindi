# Day 9 review notes (shopping)

13 scenes: source 1–9 plus the four "समस्या होने पर बातचीत" situations (1)–(4) as d09s10–d09s13.

- **Not included:** the "उपयोगी वाक्य / Useful Expressions" list at the end (no speakers, not a dialogue). Its English column is shifted by one row from "इसमें खराबी है।" onward (e.g. "इसमें खराबी है" paired with "I'd like to return this item"; "धन्यवाद" with "This item is damaged"), and "मैं यह वस्तु बदलना/लौटाना चाहता हूँ" has only "exchange" in English. Fix in the source if this list is used later.
- **Stage directions** "(कुछ देर बाद)" (scene 3) and "(अगले दिन)" (scene 8) are folded into the scene `situation`, not lines.
- **Roles:** learner `customer` (ग्राहक). `staff` (कर्मचारी, scene 1) and `shopkeeper` (दुकानदार) are both judged masculine from "सकता हूँ", "कर देता हूँ", "दे दूँगा", "बदल देता हूँ". They never share a scene, so both use male_2.
- **Feminine variants (15):** learner आया/चाहता/सकता/लेता/करता/करूँगा → आई/चाहती/सकती/लेती/करती/करूँगी; shopkeeper to learner "आप … देख सकते हैं" (d09s2), "आप … भुगतान कर सकते हैं" (d09s7, d09s12) → सकती हैं. Not changed: "हम … कर देंगे / बदल देते हैं" (we), "मेरे साथी … करेंगे" (about the colleague), "क्या कोई अंग्रेज़ी बोल सकता है?" (कोई, generic), "पसंद आई", "क्षतिग्रस्त निकली", "टूटी हुई" (agree with वस्तु).
- **Hindi to check (report only):** d09s4 "क्या यह सुरक्षित पैक कर देंगे?" probably should be "क्या आप इसे सुरक्षित पैक कर देंगे?". गलत (d09s10) usually ग़लत. "मध्यम (Medium)।" contains English in brackets; TTS will read both words.
- **Prices** are written as ₹2,000, ₹1,200, ₹1,500, ₹1,300, ₹2,400, ₹3,450 in the Hindi. Roman spells them out as spoken (do hazaar, baarah sau, pandrah sau, terah sau, chaubees sau, teen hazaar chaar sau pachaas rupaye). Check TTS reads the symbols the same way; spell out in Hindi if not.
- **English that says more or less than the Hindi:** d09s1 "Certainly. What would you like?" (no "certainly" in Hindi); d09s2 "No, that's all. Thank you." (no thank-you); d09s3 "It fits well" for "यह बहुत अच्छा है"; "We have kurtas…" for "आपके लिए … उपलब्ध हैं"; d09s6 "That's a good deal" for "ठीक है"; d09s7 "We accept credit cards, cash, and UPI" for "आप … भुगतान कर सकते हैं"; d09s9 "I'd prefer a replacement" for "मुझे दूसरी वस्तु लेनी है"; d09s13 "My colleague will be happy to assist" for "मेरे साथी … करेंगे" (साथी may be plural/honorific).
- d09s3: the shopkeeper offers दुपट्टा and साड़ी to every learner; fine for both variants, but note for the male variant.
- **Roman to check:** hastshilp, smriti-chihn, nakkaashee (नक्काशी, no nukta in source), kalaakritiyaan, pahankar, vah (वह), ye (ये), naqad, antarraashtreey, UPI.
